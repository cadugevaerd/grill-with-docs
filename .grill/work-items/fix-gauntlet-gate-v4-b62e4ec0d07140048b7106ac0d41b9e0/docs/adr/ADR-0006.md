# ADR-0006 — `state.json:workflow.version` vira `workflow.schema`, com dual-read

- status: accepted
- evidence-status: verified

- supersedes: none

## Contexto

O bloco `workflow` do `state.json` carrega `version: "v2"` num bundle cujo `WORKFLOW.md` é
v4 e cujo `development.workflow_version` é `"v4"`. O nome sugere que o campo rastreia a
versão do documento. Não rastreia, e nunca rastreou:

- writer `grill_workspace.py:691` grava o literal `"v2"`; `workflow_info()` (645-651)
  computa apenas `path` e `sha256`, nunca versão alguma;
- reader `audit_decisions.py:801` compara contra o literal `"v2"`;
- `validate_workspace_contract.py:278,944` afirmam `== "v2"`; as fixtures de
  `tests/fixtures/*/state.json:21` gravam `"v2"`.

Quatro lados fixam o mesmo literal e nenhum calcula nada. É uma tag de schema congelada
que empresta o nome de versão de workflow — e induziu, nesta própria sessão, a leitura
errada de que o bundle estava com versão inconsistente.

## Decisão

O campo passa a se chamar `workflow.schema`, mantendo o valor `"v2"`. O reader aceita as
duas grafias: `schema` quando presente, `version` como fallback. Bundles já materializados
não migram.

## Consequências

- `grill_workspace.py:691` emite `schema`; `audit_decisions.py:801` lê `schema` com
  fallback para `version`, para os nove bundles existentes deste repositório seguirem
  auditáveis sem migração.
- `validate_workspace_contract.py:278,944` e as fixtures passam a exercitar a grafia nova,
  e ganham um caso que prova o fallback lendo um `state.json` com `version`.
- A string de finding `state: workflow version divergence` é saída visível da auditoria;
  renomeá-la para falar de schema muda texto que consumidores podem casar.
- O dual-read é permanente, não janela de migração: nada reescreve bundle existente.

## Alternativas rejeitadas

- **Fora de escopo com BL**: manteria a armadilha viva sem falha que force o conserto.
- **Só comentar writer e reader**: não alcança quem lê o `state.json` bruto, que é
  exatamente como a leitura errada aconteceu aqui.

# ADR-0204 — Bootstrap declarado: a primeira entrega não é atestada por si mesma

## Contexto

Este work item entrega o emissor da cadeia de atestação. Enquanto ele não
existir, nenhuma etapa do ciclo pode ser concluída — inclusive as etapas deste
próprio work item. A entrega é circular por natureza.

## Decisão

O ciclo corre normalmente. As etapas ficam `in-progress` enquanto o emissor não
existe, porque `complete` exige a cadeia. Terminada a implementação, o emissor
recém-criado fecha as etapas: os artefatos existem, os digests são reais, e a
correlação que a cadeia afirma é verdadeira.

O bootstrap é **declarado**, não disfarçado: o estado do work item mostra etapas
abertas enquanto elas estiverem abertas, e o registro diz por quê.

## Opções e custos

- **A: bootstrap declarado na trilha feature.** Benefício: o trabalho planejado
  passa pelo protocolo planejado, e a circularidade fica visível em vez de
  contornada. **Custo:** o work item passa um intervalo com etapas abertas, e
  qualquer projeção de status o mostra como incompleto durante esse intervalo.
- **B: entregar pela trilha de incidente.** Benefício: `hotfix-go` não exige
  atestação, então fecharia hoje. **Custo:** usar uma trilha de contenção de
  incidente para entregar feature planejada com três ADRs esvazia as duas
  coisas — a trilha deixa de significar incidente, e o work item planejado vira
  ornamento.
- **C: emitir a cadeia à mão para as próprias etapas.** Benefício: fecharia sem
  mudar trilha. **Custo:** é exatamente a fabricação de evidência que este work
  item existe para tornar desnecessária.

## Consequências

- Fechar as etapas retroativamente é legítimo **porque** os artefatos já
  existem e são lidos no momento da emissão. Não é carimbo: é a mesma
  verificação que qualquer etapa futura receberá.
- A ordem é obrigatória: implementação primeiro, emissão depois. Emitir antes de
  o artefato existir seria selar o vazio.
- Se a implementação for abandonada, as etapas permanecem abertas e o work item
  permanece incompleto — que é o registro correto do que aconteceu.

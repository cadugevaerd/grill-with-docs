# ADR-0003 — Detecção do ponytail por `kind: harness-plugin`, lendo o registro de plugins do harness em disco

## Contexto
Os kinds atuais (`runtime|binary|path|harness|specify-extension`) só enxergam binários no PATH, caminhos relativos ao repositório ou skills materializadas em `.claude/skills`/`.agents/skills`. Um plugin de harness vive fora do repositório: Claude Code registra em `~/.claude/plugins/installed_plugins.json` (`ponytail@ponytail` → version, installPath, scope) e mantém cache em `~/.claude/plugins/cache/<marketplace>/<plugin>/<versão>/`; Codex mantém cache com o mesmo layout em `~/.codex/plugins/cache/` e `codex plugin list` só emite texto. Não foi encontrado registro JSON de instalados no Codex (EVIDENCE GAP registrado em BL-0001). O detector já tem a seam `Toolchain` para ambiente e leitura injetáveis.

## Decisão
Criar o kind `harness-plugin` em `dependencies.json`/`ensure_dependencies.py`. A detecção lê arquivo, sem subprocesso: no runtime `claude`, a entrada `<plugin>@<marketplace>` de `installed_plugins.json` (versão e caminho); no runtime `codex`, o diretório `~/.codex/plugins/cache/<marketplace>/<plugin>/<versão>/.codex-plugin/plugin.json` (versão). Status `present|outdated|missing`, com `min` opcional. A raiz do home de cada harness é resolvida pela `Toolchain` (`environ`), como já se faz para `${HOME}` em `search_paths`.

## Opções e custos
- **A (escolhida): leitura de arquivo.** benefício: offline, determinística, testável por fixture, sem timeout; **custo:** no Codex não distingue instalado de habilitado (BL-0001).
- **B: CLI do dono (`claude plugin list --json`, `codex plugin list`).** benefício: fonte autoritativa; **custo:** subprocesso com timeout, parse de texto frágil no Codex, exige CLI no PATH do preflight.
- **C: híbrido.** benefício: cobre ausência do arquivo; **custo:** dois caminhos de código e de teste para um ganho não demonstrado.

## Consequências
- `KINDS` ganha `harness-plugin`; `tests/validate_dependencies_contract.py` ganha casos por runtime com fixtures de registro/cache.
- O manifesto passa a declarar `plugin`, `marketplace` e, por runtime, o caminho do registro; nada disso baixa bytes.
- Mudança em `plugin/**` → bump obrigatório (DQ-0007).

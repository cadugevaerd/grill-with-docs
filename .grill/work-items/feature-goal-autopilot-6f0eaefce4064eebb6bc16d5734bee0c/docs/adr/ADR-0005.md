# ADR-0005 — Pontos de interação: lista fechada com residual fail-closed

## Contexto

Uma lista puramente fechada trata toda situação não prevista como autorizada a
seguir, que é o waiver implícito proibido pela cláusula **Fail-closed sem
waiver**. Um critério sem enumeração não é auditável: duas execuções param em
lugares diferentes.

## Decisão

`goal.md` enumera os pontos de interação conhecidos **e** fecha com uma
cláusula residual: qualquer ambiguidade, evidência ausente ou decisão não
coberta pela lista também emite `GOAL-HOLD`.

### Trilha pré-ciclo (GWD)

| Ponto | Origem |
|---|---|
| pergunta material da entrevista (`ASK_ONE`) | protocolo GWD — uma pergunta atômica por rodada |
| `SAFETY_STOP` | duas rodadas sem progresso, três expansões consecutivas ou 25 perguntas materiais |
| `BLOCKED-CONSTITUTION` (exit 3) | cobertura ausente/duplicada, `PENDING`, `UNMAPPED`, hash stale |
| auditoria `NO-GO` (exit 1) | `audit` |
| `BACKLOG-REQUIRED`, `MISSING-DEPENDENCY`, `--allow-install` | `init`/`preflight` — `--allow-install` é decisão de confiança em catálogo de terceiros |
| `ROOT-CAUSE-UNPROVEN` e escolha de rota | `triage` — o core não classifica linguagem natural |
| `PLAN_ONLY_STOP` | fronteira entre as trilhas |

### Trilha ciclo v4

| Ponto | Origem |
|---|---|
| `ship` | `WORKFLOW.md`: a autorização humana permite invocar a skill registrada |
| `BLOCKED_CAPABILITY` | skill ausente, ambígua, abaixo da versão mínima, hash divergente ou catálogo não confiável — sem fallback para etapa `required` |
| `UNATTESTED_STEP_OUTPUT`, `POLICY_VIOLATION/DIRECT_STEP_EXECUTION` | tentativa de emulação semântica |
| `GRANT-SCOPE-VIOLATION`, conflito de merge, `DIRTY-WORKTREE` | `implement-parallel` / `converge` / `reconcile` |
| retorno "when blocked" de qualquer etapa | tabela de 11 etapas do `WORKFLOW.md` |

### Cláusula residual

Fora da lista, o loop segue sozinho **apenas** enquanto a próxima ação for
determinística e reversível. Ambiguidade, evidência faltante, decisão de valor
ou side effect irreversível emitem `GOAL-HOLD` mesmo sem estar enumerados.

## Consequências

- A lista é acoplada à versão do `WORKFLOW.md` e do core: gate novo exige
  revisão do `goal.md`, e o marcador versionado é o que torna essa revisão
  visível em diff.
- `PLAN_ONLY_STOP` e `ship` são paradas obrigatórias e não configuráveis. A
  primeira decorre da cláusula **Feature/fix plan-only**, a segunda do próprio
  `WORKFLOW.md`.

## Alternativas rejeitadas

- **Lista fechada sem residual**: mais autônoma, mas transforma toda situação
  não prevista em autorização implícita.
- **Só critério**: documento curto e resistente a versão, porém não auditável.

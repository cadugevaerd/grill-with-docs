# ADR-0005 — i-have-adhd obrigatório no GWD

- supersedes: none
- conflicts-with: none

## Contexto
O usuário exige i-have-adhd instalado nos dois ambientes e funcional por padrão. Confirmou o alcance: no projeto GWD e, após atualizar a skill GWD, nos CLIs Codex e Claude Code.

## Decisão
Adicionar i-have-adhd à stack obrigatória. A skill GWD atualizada aplica o padrão no projeto/fluxo GWD sem invocação manual do i-have-adhd. Sessões fora do GWD conservam o padrão anterior. Preservar configurações existentes e a política de implementação Ponytail. Instalação, habilitação, carregamento automático e comportamento observado em sessão nova de cada CLI precisam de evidências distintas.

## Alternativas e consequências
Default global foi descartado pela resposta do usuário. Invocação manual a cada sessão não satisfaz o pedido. A versão 0.3.0 está instalada e habilitada nos dois harnesses; os testes isolados do hook passaram. Isso não prova a integração futura da skill GWD nem comportamento em sessão nova. O mecanismo local e os testes de integração serão definidos no plan e executados no ciclo externo; o core permanece stdlib e a instalação delegada às CLIs responsáveis.

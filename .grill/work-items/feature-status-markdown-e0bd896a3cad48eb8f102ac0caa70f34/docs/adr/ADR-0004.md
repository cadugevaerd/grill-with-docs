# ADR-0004 — A nova interface publica a versão 3.4.0

## Contexto

A mudança adiciona `--format markdown`, campos JSON aditivos e comportamento visível da skill. É capacidade nova compatível com o contrato JSON existente. A versão atual é `3.3.2`, e a Constituição exige bump antes de merge ou push e release correspondente à tag.

## Decisão

Aplicar bump minor `3.3.2 → 3.4.0`, atualizar todas as superfícies fixadas pelo validador, registrar a mudança no changelog e deixar o pipeline criar tag e release ancoradas no mesmo commit após merge na `main`.

## Opções e custos

- **Minor 3.4.0 (escolhida):** comunica nova capacidade compatível; **custo:** exige sincronização de manifests, documentação e publicação.
- **Patch 3.3.3:** menor incremento; **custo:** subdeclara uma interface pública nova.
- **Major 4.0.0:** sinaliza ruptura; **custo:** não corresponde à preservação do JSON padrão.

## Consequências

Nenhuma tag existente é reutilizada. A implementação só pode alcançar ship depois que o gate de distribuição confirmar a versão idêntica e a automação de release estiver coberta.

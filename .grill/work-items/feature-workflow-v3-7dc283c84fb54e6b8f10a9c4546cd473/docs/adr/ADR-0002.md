# ADR-0002 — Required steps use only pinned canonical skills

## Contexto
Uma aproximação por agente pode produzir texto semelhante a uma etapa concluída sem provar que a capacidade autorizada foi usada.

## Decisão
Cada etapa exigida de V3 resolve para uma única identidade em registro confiável; runtime sem entrypoint comprovado bloqueia em vez de receber fallback.

## Opções e custos
- **Skill canônica pinada:** produz evidência auditável; **custo:** cobertura de runtime cresce apenas quando há prova de capacidade.
- **Fallback semântico:** aumenta cobertura imediata; **custo:** aceita execução não autorizada e destrói atribuição confiável.

## Consequências
Ship exige autorização humana adicional, mas essa autorização nunca substitui a skill canônica nem valida execução direta.

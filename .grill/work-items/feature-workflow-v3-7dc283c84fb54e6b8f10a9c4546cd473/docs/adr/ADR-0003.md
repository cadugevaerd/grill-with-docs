# ADR-0003 — Linked worktrees share an integrity-checked project store

## Contexto
Registros independentes por worktree ocultam conflito e tornam difícil provar qual estado é o atual.

## Decisão
Work Item V3 coordena-se por um Project Store compartilhado no diretório comum do Git, com revisões verificadas e journal ordenado.

## Opções e custos
- **Store compartilhado:** expõe concorrência e preserva história auditável; **custo:** escritores precisam usar locks e CAS.
- **Estado local por worktree:** simplifica cada diretório; **custo:** permite divergência silenciosa entre cópias.

## Consequências
Migração, identidade e atualizações concorrentes devem falhar fechado quando o snapshot, o journal ou o lock não forem consistentes.

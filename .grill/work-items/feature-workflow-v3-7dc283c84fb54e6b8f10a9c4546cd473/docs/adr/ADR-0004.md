# ADR-0004 — V3 attestation is cooperative structural evidence

## Contexto
O plugin coordena agentes cooperativos em Codex, Claude Code e runtimes similares; não tem como objetivo resistir a um executor que tenta forjar o próprio histórico.

## Decisão
O checkpoint V3 exige uma cadeia estrutural completa e correlacionada, preparada pelo coordenador ou subagente designado. Ela é evidência auditável de coordenação, não prova criptográfica de execução.

## Opções e custos
- **Atestação cooperativa:** funciona sem serviço externo ou segredos; **custo:** não detecta agente malicioso que falsifica recibos.
- **Atestação independente assinada:** resiste a falsificação pelo executor; **custo:** exige autoridade externa, credenciais protegidas e integração específica por runtime.

## Consequências
Ausência, replay, divergência, execução direta e terminal inválido continuam bloqueando. Proveniência criptográfica pode ser adicionada futuramente como capability separada, sem reinterpretar recibos V3 existentes.

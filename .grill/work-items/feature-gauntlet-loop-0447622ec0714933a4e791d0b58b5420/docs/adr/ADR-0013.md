# ADR-0013 — Ciclo de vida de wave estendido no Store

O Store shipado pela FASE-002 declara exatamente uma wave por run, congelada no estado `DECLARED` e imutável byte a byte após a criação. A FASE-003 precisa de waves sucessivas com progresso real para paralelizar os nós independentes do Execution DAG dentro de `agent-execute`.

A FASE-003 estende o schema do Store: `WAVE_STATES` ganha um conjunto fechado adicional (por exemplo `DECLARED → ACTIVE → COMPLETE`) e a regra de imutabilidade passa de "o mapa `waves` inteiro é imutável" para "uma wave superada é imutável assim que uma wave seguinte é declarada; a wave corrente pode transicionar de estado; o mapa só cresce por acréscimo". Essa extensão é propriedade do coordenador — não concede autoridade nova a nenhum worker e preserva a fronteira ADR-0006/ADR-0010. Cada evento de dispatch, conclusão, stall, recovery e retry correlaciona à wave corrente pelo seu identificador distinto.

# ADR-0001 — Política de Model Tier

O Loop usa tier pequeno para checklist e Markdown, médio para tasks, agent-execute, converge e verify, e grande para specify, plan, analyze, agent-assign, review e ship. Promoção ocorre antes do dispatch e fica registrada; não há downgrade silencioso.

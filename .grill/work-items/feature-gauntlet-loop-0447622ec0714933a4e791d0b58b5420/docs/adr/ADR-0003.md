# ADR-0003 — Worker Worktrees isolados

Cada worker paralelo recebe worktree e branch filhos no commit-base da tarefa; nenhum worker escreve no worktree do coordenador. Worktrees de falha ou bloqueio são preservados para diagnóstico.

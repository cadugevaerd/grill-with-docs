# ADR-0004 — DAG explícito no workflow V3

`tasks` produz o DAG versionado e o Loop paraleliza somente nós sem dependências pendentes. A primeira versão preserva as onze macroetapas V3 na ordem canônica, sem extensões configuráveis.

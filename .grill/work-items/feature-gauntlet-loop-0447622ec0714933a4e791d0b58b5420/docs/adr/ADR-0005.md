# ADR-0005 — Recuperação limitada de stalls

Após quinze minutos sem progresso, o coordenador substitui uma vez o worker ou relança uma vez o Loop; recorrência bloqueia com diagnóstico. Apenas falhas transitórias classificadas recebem nova tentativa automática.

# Model Tier policy for the Gauntlet Loop

O Gauntlet Loop usa o menor Model Tier capaz: pequeno para checklist e atualizações Markdown, médio para tasks, agent-execute, converge e verify, e grande para specify, plan, analyze, agent-assign, review e ship. Promoções só acontecem antes do dispatch, por exigência declarada ou indisponibilidade do runtime, e nunca há downgrade silencioso; a política preserva capacidade proporcional ao impacto da decisão.
